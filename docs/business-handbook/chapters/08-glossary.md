# Глоссарий

| Термин | Значение в продукте |
| --- | --- |
| УЭЦН | Установка электроцентробежного насоса |
| ЭЦН | Электроцентробежный насос |
| ПЭД | Погружной электродвигатель |
| НКТ | Насосно-компрессорные трубы |
| ВНЭ | Вязкие нефтяные эмульсии |
| ЧРЭП | Частотно-регулируемый электропривод |
| Дебит | Количество добываемой продукции за единицу времени; единица указывается с показателем |
| Телеметрия | Измерения параметров оборудования и скважины во времени |
| Уставка | Заданное значение параметра; отличается от измерения датчика |
| Фонд | Совокупность скважин в согласованной области работы |
| Выборка участников | Зафиксированный состав объектов конкретного расчёта или контура |
| ID Pulse | Внутренний идентификатор скважины в Pulse |
| Pulse Connector | Название источника данных в текущем интерфейсе; не меняет происхождение данных |
| Проверка | Расчёт по выбранному входу и периоду с сохранённым результатом |
| Риск | Численный выход модели, интерпретируемый по её версии и правилу |
| Ярус | Норма, наблюдение или тревога по правилу накопленных срабатываний |
| Тревога | Сигнал для рассмотрения; не равен подтверждённому физическому отказу |
| Недостаточно данных | Для выбранной оценки не хватает пригодных каналов или истории |
| Заключение | Сохранённое решение специалиста по случаю |
| Отказ | Подтверждённое событие с датой и причиной |
| Архив | Состояние карточки вне оперативного представления с сохранением истории |
| Паспорт оборудования | Сведения об оборудовании, эпизодах установки и истории изменений |
| Область доступа | Перечень данных, с которыми разрешено работать пользователю |
| Recall | Доля целевых событий, обнаруженных по заранее выбранному правилу |
| F1-macro | Среднее F1 по классам с одинаковым весом каждого класса |
| Confusion matrix | Таблица соответствия истинных и предсказанных классов |
| Научная приёмка | Независимая проверка качества модели на согласованных данных |
| Промышленная приёмка | Подтверждение пригодности системы к согласованным условиям эксплуатации |
| Синтетические данные | Искусственно подготовленные данные для испытаний; не доказательство точности на производстве |
| ROI | Отношение чистого эффекта к дополнительным затратам за один согласованный период |

Предметные основания: [S1](../SOURCES.md#s1-назначение-и-модель), [S2](../SOURCES.md#s2-локальный-контур), [S5](../SOURCES.md#s5-предметные-сценарии), [S6](../SOURCES.md#s6-паспорт-оборудования). Определения показателей пилота уточняются в его протоколе.
