# Возможности и ограничения

Ниже приведён срез документации исходников на 25 октября 2026 года. Для пилота команда внедрения отдельно подтверждает версию установленной системы, включённые режимы, доступ и пригодность данных.

## Карта возможностей

| Возможность | Что описано в текущих исходниках | Условие использования и граница |
| --- | --- | --- |
| Реестр и карточка скважины | ID Pulse, текущие сведения, активность, архив и история изменений | Разрешённая область данных; архив независим от активности |
| Телеметрия | Каналы, графики, таблица качества, сравнение периодов, импорт и экспорт | Доступная история источника; разрешение данных указывается рядом с периодом |
| Проверка периода | Запуск проверки и сохранённый результат с объяснением и сведениями о модели | Доступный сервис модели, разрешения и достаточные данные |
| Заключения и физические отказы | Обработка случая, история заключений, регистрация отказа | Заключение и физический отказ — разные действия |
| Общая история событий | Список событий и точное сохранённое основание | Текущие права на источник события; текущее состояние не подменяет историческое |
| Персональный вход | Учётные записи и серверные сеансы | Соответствующий профиль запуска; публичная саморегистрация не заявлена |
| Настраиваемые права и группы | Разрешения на действия, группы и организационная область | Требуется отдельное включение режима; имя роли не определяет полномочия |
| Профили сотрудников | Справочные сведения о сотруднике и руководителе | Сведения о месте работы не заменяют разрешения |
| Паспорт оборудования | Серверный API: насос, ПЭД, станция управления, эпизоды установки, ручная запись, XLSX, история | Персональный вход, включённые настраиваемые права, явное разрешение и подготовка БД; готовность пользовательского экрана отдельно не заявляется |
| Сохранённая проверка файла | Принятое задание, состояния, результат и повторное открытие | По умолчанию выключена; испытания ограничены синтетическими данными |
| Устойчивый расчёт выборки и сбор | Отдельные сохраняемые задания расчёта и получения измерений | По умолчанию выключены; синтетическая область; рабочий портал автоматически не переключается |

Основания для строк карты: [S2](../SOURCES.md#s2-локальный-контур), [S3](../SOURCES.md#s3-интерфейс-и-история), [S4](../SOURCES.md#s4-доступ), [S5](../SOURCES.md#s5-предметные-сценарии), [S6](../SOURCES.md#s6-паспорт-оборудования).

## Что требует отдельной поставки или приёмки

| Направление | Текущее ограничение |
| --- | --- |
| Предупреждение за 7–14 суток | Цель проекта; независимая научная приёмка текущего комплекта не выполнена |
| Определение всех 13 причин отказа | Целевая таксономия; текущая бинарная модель не подтверждает такую детализацию |
| Производственная надёжность | Численные SLA, время восстановления и допустимая потеря данных согласуются и проверяются отдельно |
| Внешний корпоративный вход | Полный SSO/OIDC не заявляется подключённым |
| Доставка уведомлений | Показ тревоги в интерфейсе не подтверждает отправку, доставку и прочтение сообщения адресатом |
| Помощник Pulse | Архитектурное предложение; реализация и условия размещения модели отдельно не приняты |
| Экономический результат | Требует наблюдений пилота и согласованной методики; гарантированные проценты экономии не установлены |

Источники ограничений: [S1 Модель](../SOURCES.md#s1-назначение-и-модель), [S7 Будущие функции](../SOURCES.md#s7-будущие-функции).

## Как описывать готовность заказчику

Для каждой демонстрируемой функции нужно назвать её версию и контур, показать разрешённый сценарий с исходом и зафиксировать ограничения. Макет показывает задуманный интерфейс; программная проверка подтверждает поведение в своей области; производственный результат оценивается на данных эксплуатации.

Отдельно учитывать состояния «не рассчитано», «недостаточно данных» и «ошибка». Количество скважин в выборке не равно числу пригодных оценок, а пустое значение риска не заменяется нулём.
