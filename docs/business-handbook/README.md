# Бизнес документация Пульс скважины

«Пульс скважины» помогает технологу выбирать скважины для проверки, разбирать телеметрию и сохранять обоснованное решение по состоянию электроцентробежного насоса. Этот справочник предназначен для заказчика, руководителя пилота, технологов и команды внедрения.

**Начните с [HTML версии с поиском](index.html).** Здесь описаны назначение продукта, рабочие сценарии, границы доступных возможностей и предложенный порядок оценки пользы. Горизонт предупреждения за 7–14 суток — цель проекта; подтверждённый экономический эффект и промышленная точность модели пока не заявляются.

Редакция от **25 октября 2026 года**. Возможности сверены с документами текущих исходников. Это дата документационной сверки; состояние конкретной установленной системы подтверждается отдельно перед пилотом.

## Как пользоваться

Заказчику и руководителю пилота: продукт → возможности → пилот → экономика. Технологу: рабочие сценарии → предметные правила → глоссарий. Команде внедрения: возможности → условия пилота → источники.

Во всех разделах различаются **описанная реализация**, **включение в конкретном контуре** и **цель развития**. Наличие функции в исходниках, макете или техническом испытании не подтверждает её доступность пользователю и не заменяет промышленную приёмку.

Подробности архитектуры и эксплуатации находятся в [техническом справочнике](../project-handbook/index.html). Эта дополнительная ссылка работает, когда оба комплекта расположены рядом в workspace; отдельный бизнес-архив содержит все собственные разделы и реестр оснований.

## Передача и обновление

Для передачи используйте `pulse-business-documentation.zip`: HTML, Markdown, знак продукта, сборщик, валидатор и реестр источников находятся внутри. Страница открывается без приложения, сервера и сети. Поиск работает по тексту разделов; печать выводит весь справочник.

Порядок сборки, проверки и содержательной сверки описан в [источниках](SOURCES.md#актуализация).
