# Примеры запросов

Это иллюстративные данные, не копии рабочих измерений. Перед использованием выберите существующий ID Pulse и доступный период.

json-source.json задаёт **целевой** источник, выдающий ID Pulse. Текущий генератор Data использует собственные внешние ID; до согласованного изменения его контракта требуется well_identity=unitek и существующие серверные привязки. Простая подстановка well_identity=pulse к текущему потоку не выполняет миграцию ID.

manual-check.json — тело POST /api/v1/wells/{well_id}/checks. request_id должен быть стабильным UUID/ключом повтора для одного периода, а не общей константой на все проверки. telemetry-batch.json — тело source ingest с records; в прямом импорте используется другой конверт points. Маркер 9999 в R_izol должен очиститься в null, F_out=0 остаётся нулём.
