# Каталог макетов Figma

Главный файл: [Figma](https://www.figma.com/design/km4tIbp3LnMTRrV6yi6Qho). Каталог сформирован из локальных реестров проекта; ссылки требуют доступа к этому Figma-файлу. Размеры, если отсутствуют в реестре, указаны по базовой композиции; точную геометрию узла проверяют в Figma.

Узлы представляют макеты и состояния, а не отдельные готовые приложения. В частности, подписи demo/показательный фонд и старый порядок вкладок в части макетов предшествуют последним продуктовым решениям. Прямые переходы Figma не выполняют серверные операции.
