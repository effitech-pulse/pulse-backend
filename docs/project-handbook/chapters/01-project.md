# Назначение и границы проекта

«Пульс скважины» — система диагностики электроцентробежных насосов нефтяных скважин. Основной пользователь — технолог: он оценивает риск, изучает телеметрию, проверяет модельное подозрение и фиксирует заключение. Администратор управляет реестром, источниками и доступом. Разработчик модели работает в отдельном исследовательском контуре.

Горизонт 7–14 суток — цель проекта. Он не является доказанной характеристикой текущей модели. Подозрение модели не означает подтверждённый отказ; отсутствие достаточных данных не означает нормальный режим.

## Термины

| Термин | Значение |
|---|---|
| ID Pulse | Внутренний `well.id` операционного приложения |
| Внешний ID | Идентификатор конкретной системы мониторинга; используется только для сопоставления |
| Риск | Численный результат модели для окна наблюдения |
| Ярус | Норма / наблюдение / тревога, присваиваемые по правилу накопленных срабатываний модели |
| Статус обработки | Решение технолога по случаю; существует независимо от риска и яруса |
| Окно | Отрезок прошлого, из которого рассчитываются признаки |
| Watermark | Последнее принятое время измерений источника |
| Сбор | Получение, нормализация и сохранение измерений |
| Скоринг | Применение модели к подготовленному входу |
| Pulse Connector | Согласованное название источника; технический cohort `presentation-v1` фиксирует 100 существующих ID Pulse. Membership не равно active/archive или числу рассчитанных скважин |
| Pulse Data | Текущее имя репозитория и сервиса сбора/генерации; не обязано совпадать с названием источника в интерфейсе |

## Приоритет документации

Описание текущей реализации опирается на рабочее дерево исходников, а не только на последний Git-коммит. Согласованные изменения отдельно перечислены в статусе и дорожной карте. Дизайн Figma определяет визуальную цель, но наличие экрана в Figma не означает наличие рабочего API. Исторические ML-отчёты не отменяют причинный протокол оценки.

## Граница дополнения PREP · 20.10.2026

Техническая локальная приёмка персонального доступа, когорты и сохранённых расчётов отделена от научной. Успешный пользовательский сценарий с синтетической телеметрией не подтверждает precision/recall, достоверную вероятность или горизонт 7–14 суток. Новых внешних данных сейчас нет; их получение и самостоятельное подключение ML пользователь отложил. Настоящее дополнение не переобучает модель и не продвигает кандидата. См. [PREP ledger](../references/readiness-ledger.md) и [независимый протокол](../references/independent-acceptance.md).
