## Логотип и типографика

Утверждённый знак «Поток»: два встречных канала и точка измерения. Основной цвет #2F6FED; цвет надписи #1D2B3A. Для тёмного фона есть белые версии, для печати — чёрные/монохромные. Охранное поле — 32 единицы при сетке 256; минимальный знак 16 px. Нельзя растягивать, наклонять или добавлять градиенты и тени.

Интерфейс использует Roboto 400/500 через локальный `@fontsource/roboto`. Основной текст 14/20 px, подписи 13/19 px, вторичный текст 12/17 px, заголовок страницы 28/40 px, метрика 32/45 px. Надпись в SVG-логотипе переведена в кривые и не требует установленного шрифта.

Коллекция Figma «Пульс / Токены» содержит режимы Light/Dark; тёмные примитивы находятся в «Пульс / Палитра Dark». Измеренный контраст макетов не заменяет аудит производного CSS в браузере. Отдельные состояния Ant Design формируются его алгоритмом темы.

Источники реализации: `pulse-frontend/src/theme/designTokens.ts`, `antdTheme.ts`, `ThemeProvider.tsx`, `src/index.css`. Тема хранится в `localStorage[pulse-theme]`; смена темы сохраняет текущую страницу.

## Композиция и компоненты

Боковая навигация — 224 px; шапка контекста — 64 px; рабочий отступ desktop — 32 px. Навигация группируется по задачам; профиль и разработчик находятся внизу. На небольшом экране панель сворачивается, таблицы допускают горизонтальную прокрутку. Основные макеты: 1440, 1280 и 1024 px; полный мобильный сценарий приложения не принят.

| Компонент | Назначение и состояния |
|---|---|
| Button Primary/Secondary | Основное действие, дополнительное действие; hover/focus/disabled/loading |
| Badge Alert/Watch/Normal | Ярус; текст обязателен, цвет не единственный сигнал |
| Navigation Active/Default | Активная полоса, иконка, название раздела |
| Form Field | Label, подсказка, ошибка, обязательность, загрузка |
| Table | Загрузка, пустой набор, ошибка, пагинация, сохранённые фильтры |
| Telemetry Chart | Hover, пропуски, выбор каналов, zoom/pan, выделение периода, синхронное сравнение |
| Dialog/Drawer | Фокус, отмена, ошибка, ожидание, конфликт версии |
| Notification | Не более трёх одновременно, отдельный таймер 4 секунды; история сохраняется — целевое поведение макетов |

В React используются существующие компоненты Ant Design; сгенерированный из Figma код адаптируется к ним и к сетке приложения. Изображение целого экрана не служит реализацией интерфейса. В документации находятся нативные SVG-ресурсы и локальные дизайн-реестры, а не выданный за рабочий продукт прототип.

## Правила представления данных

Риск, ярус и статус обработки показываются раздельно. У пропуска на графике должен быть разрыв; валидный ноль отображается как ноль. Указаны период, часовой пояс, разрешение сетки, ограничения выборки и источник значений. Нельзя выдавать медианное заполнение признака за показание датчика. Общая шкала разных физических единиц допускается только с явным преобразованием либо двумя осями.

Перед выпуском сверяются геометрия, статические ресурсы, светлая/тёмная темы, клавиатурная навигация, фокус, контраст, ошибки и загрузки. Полная визуальная приёмка всего Figma-файла ещё не проведена.

## Прототипы и офлайн просмотр

Главная HTML-документация и фирменный комплект доступны без сети. Исторический прототип v3 может обращаться к сторонним CDN для библиотек; он приложен отдельно для справки и не заменяет рабочий интерфейс. Прямые ссылки Figma требуют доступа к файлу.
