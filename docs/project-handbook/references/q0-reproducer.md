# Q0 process reproducer

Test-only source for `internal/transport/httpapi/file_inputs_process_test.go`.
It recreates all eight q0-p-v1 datasets in a new operator-owned directory.
No generated datasets, binary, virtualenv or real weights belong in Git.
The 45-byte `q0_synthetic.FixedModel` pickle is trusted synthetic fixture source:
it returns a fixed probability. The launcher observes actual installed server,
loader and feature functions. This verifies orchestration, not model quality.
Never substitute another pickle. Keep the module name `q0_synthetic` unchanged.

## Inputs and identities

`fixtures/manifest.json` contains immutable original dataset SHA/lengths;
`fixtures/xlsx-metadata.json` retains original per-entry ZIP metadata. Generator
uses CPython **3.13.5**, runtime zlib **1.2.12**, DEFLATE level6 and fixed ZIP time
2026-10-20 22:21:50. Original generation Python/zlib versions were not recorded;
current full byte parity, rather than inferred history, establishes equivalence.
Full generation refuses other Python/zlib versions and an existing output root.
Any SHA mismatch is an error: retain the failed output for diagnosis, never edit
expected identities to make a new fixture appear historical.

`fixtures/accepted-identity.json` records accepted installed source/runtime
manifests. `fixtures/pin.json` retains their strict expected hashes. The registry
contains four immutable synthetic artifacts (bundle manifest/model/meta/drift).
`source-provenance.json` records source refs and helper/wheel lineage;
`checksums.json` covers the retained source tree, excluding itself.

Python dependencies for generation/selftests are stdlib only. Actual ML needs
all versions in `requirements-accepted.txt` in an isolated Darwin/arm64 venv;
that file is an installed version inventory, **not** a reproducible wheel lock.
`accepted-wheels.json` records the accepted private wheel SHA where established.
The candidate contracts0.1.2 is UNRELEASED. Obtain reviewed wheels from your
trusted artifact store or build from the recorded source refs; verify wheel SHA
before installing. An unavailable historic wheel is a gate, not permission to
use a same-version substitute. No public download endpoint is asserted here.

Example installation, with operator-provided absolute paths (no editable
installs and no shared workspace environment):

```sh
python3.13 -m venv "$Q0_ENV"
"$Q0_ENV/bin/python" -m pip install --no-index --find-links "$Q0_WHEELHOUSE" \
  -r test/q0_process/requirements-accepted.txt

# exact local paths first; package versions alone do not establish old pin.

```

Installation can change RECORD/direct_url/generated bytes despite equal wheels
and versions. Before any process proof, compare the **actual installed** pin
without editing the retained pin. This loads only the trusted synthetic registry
and does not predict or train:


A different source/runtime requires a separately reviewed new generation/pin and
full strict proof. Cold external installation is not claimed as tested.

## Dedicated PostgreSQL and exact harness commands

Use disposable PostgreSQL16, superuser only for fixture schema/trigger management.
Never pass an app/PREP database URL. Choose a free dedicated loopback port and
unique container name; retain the actual resolved image identity.

```sh
docker run --rm -d --name "$Q0_PG_CONTAINER" \
  -e POSTGRES_PASSWORD=q0-synthetic -e POSTGRES_DB=q0_process \
  -p "127.0.0.1:${Q0_PG_PORT}:5432" postgres:16
docker exec "$Q0_PG_CONTAINER" pg_isready -U postgres -d q0_process
export TEST_DATABASE_URL="postgres://postgres:q0-synthetic@127.0.0.1:${Q0_PG_PORT}/q0_process?sslmode=disable"
```

Continue only after pg_isready succeeds. Harness applies migrations only inside
its unique `q0_p_*` schemas and cleans those schemas. Do not use `make migrate`.
Clear unrelated inherited Q0 fault/control/child variables and OTel/Python
configuration. The supported `OBSERVABILITY_EXPORT_ENABLED=false` is set by the
harness; do not prefill `Q0_CHILD`, `Q0_READY`, `Q0_SCHEMA` or `Q0_ML_ADDR`.


Actual child listener binds `127.0.0.1:0`; no application port is reused. Resource
runner is **Darwin-only**: `/usr/bin/time -l` reports OS maximum RSS in bytes;
100ms process-tree sampling supplements it. Linux time units/flags are different
and unsupported. Bounds: Go1GiB, ML2GiB, combined owned parser+ML temp128MiB;
resource child40s, gateway/ML5min, actual adapter RPC30s. W3/W4 must remain ≤1GiB.
Do not change caps, workload, timing, sleeps or GC to obtain acceptance.

W2 checks128 columns and XML spill; W2columns rejects129. W3raw rejects20MiB+1;
W3rows rejects100001; W3 accepts100000rows/20MiB/64 mappings. W4 rejects amplified
canonical>50MiB. W5count checks16/17; W5 checks account/global byte quota, one race
winner, duplicate uncharged and actual overlapping payload-free metadata reads.
Replay exercises both SIGKILL-after-commit barriers against PostgreSQL/separate
ML. Faults cover strict pin failures. No mock substitutes are permitted.

## Evidence and gates

Retain top-level stdout/stderr plus `evidence/` files: process/time/log records,
per-case outcome JSON, DB before/after relation/TOAST/WAL snapshots, go-events,
ml-calls, readiness/barrier signals and per-reader metadata intervals/errors and
latencies. Preserve STOP/FAIL and older identities; summary PASS alone is not
proof. Metadata intervals must actually overlap, errors0 and payload-select
counter delta0. WAL reflects idle/noise and relation/TOAST accounting must not
double count. Record binary-before, exact fixtures/installed identity and finite
SHA/length inventory of evidence after final cleanup. A failure stops dependent
commands and remains gate OPEN pending coordinator/reviewer handling.

Before releasing your dedicated PG/container, inspect own process groups, temp
bytes and own schemas after harness cleanup. Stop/kill only recorded owned PIDs;
do not use broad process patterns. Retain native cleanup proof, then:


real files, credentials, production weights or installed environment trees.
