# pulse-backend — Go API

Пользователь подтвердил полный перенос прикладного backend на Go. Python ML-сервис и обучение остаются отдельными проектами. Исходный grant и ../reference/pulse-backend-python — референсы; не изменять при работе над Go API.

- Go 1.24+, net/http, pgx/v5, Excelize, grpc-go. Логи через slog, комментарии по-русски.
- Публичный /api/v1 контракт, PostgreSQL-схему и Excel-форматы сохранять; backend не считает признаки и не загружает модель.
- Схема gRPC: ../contracts/ml/v1/ml.proto; generated internal/mlpb не редактировать вручную.
- Optional/null, int64, false и нули не подменять. Ярус не вычислять из одного текущего риска и не отменять из-за data_ok=false.
- Прогоны резервировать общей PostgreSQL advisory lock; тревоги и завершение записывать атомарно. Обратную связь переносить по unitek_id.
- Миграции только явно через cmd/migrate; не применять destructive изменения к существующим данным автоматически.
- Go-тесты: go test -race ./..., go vet ./.... Интеграционные тесты — только на отдельной TEST_DATABASE_URL, с очисткой временных схем.
- Секреты и живые выгрузки не коммитить. Экспериментальные ML-инварианты остаются в model: temporal + group(oilfield) + purge/embargo, маркеры -> NaN до агрегации, валидный ноль сохранять.
